> **In-Game Description**
> _"**Acute renal failure** &mdash; No functioning kidney tissue remains. One functioning kidney or a suitable replacement can resolve this failure. Untreated complete failure becomes fatal over approximately five game days."_

This condition is part of delayed vital failure, enabled by default for supported fleshy pawns. Progression varies modestly between updates. Humans, supported fleshy HAR races, and supported bleeding fleshy Anomaly entities are included; ordinary animals are excluded.

**Treatment**: Restore at least one functioning kidney or a suitable replacement. Losing only one kidney does not create complete renal failure.

Restoring the underlying function removes the failure. Existing [hypoxic injury](/docs/wiki/injuries/hypoxia.md#hypoxia) and [lasting brain damage](/docs/wiki/injuries/brain-damage.md#brain-damage) require their own recovery or treatment. Removing all structurally surviving consciousness sources remains immediately fatal.

Use this module in a separate loadout without Death Rattle. This release does not migrate Death Rattle conditions or make removing that mod from an existing save safe.
